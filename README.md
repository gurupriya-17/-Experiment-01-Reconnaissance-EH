# Experiment 1: Reconnaissance Using NSLookup, WhatWeb and TheHarvester

## Aim
To collect preliminary information about a target organization or domain using NSLookup, WhatWeb, and TheHarvester.

## Tools Used
- NSLookup
- WhatWeb
- TheHarvester

## Procedure
1. Open a terminal in Kali Linux.
2. Use NSLookup to retrieve DNS information about the selected domain.
3. Use WhatWeb to identify publicly visible web technologies.
4. Use TheHarvester to collect publicly available information such as email addresses and subdomains.
5. Review the output from each tool.
6. Capture screenshots and document the observations.

## Screenshots
- NSLookup DNS information
- WhatWeb technology detection
- TheHarvester results

## Result
The reconnaissance procedure using NSLookup, WhatWeb, and TheHarvester will be documented based on the actual results obtained.

**Note:** Perform reconnaissance only on domains you own or are authorized to assess. Use publicly available information responsibly.
